# Админ-панель «Смотрю»

Панель открывается без отдельной формы логина и пароля. Она использует уже активную сессию Supabase от основного сайта и проверяет, добавлен ли этот пользователь в `public.platform_admins`.

## Включение

1. Выполните `admin_moderation.sql` в SQL Editor вашего проекта Supabase.
2. Узнайте UUID своего пользователя в Supabase Auth.
3. Один раз добавьте его в список администраторов:

```sql
insert into public.platform_admins(user_id)
values ('UUID_ВАШЕГО_ПОЛЬЗОВАТЕЛЯ')
on conflict (user_id) do nothing;
```

4. Войдите обычным способом на платформу и откройте `admin.html`.

В панели доступны три раздела:

- **Комментарии** — удаление комментариев;
- **Видео** — блокировка и разблокировка видео, с указанием причины;
- **Аккаунты** — блокировка и разблокировка аккаунтов, с указанием причины.

Для заблокированного видео платформа показывает:

> Извините, это видео заблокировано из-за нарушений правил платформы.

Для заблокированного аккаунта:

> Извините, этот аккаунт заблокирован за нарушения правил платформы.

Не вставляйте service_role/secret key в браузер. Панель использует только publishable key и RLS-права администратора.
