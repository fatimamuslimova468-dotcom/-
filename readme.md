<details open> <summary><h3>🎥 Лента и воспроизведение видео</h3></summary>
Вертикальная полноэкранная лента с плавной прокруткой и эффектом scroll‑snap — каждое видео занимает весь экран.

Три вкладки в верхней навигации:

🧡 Подписки — видео только от авторов, на которых вы подписаны.

🌍 Лента — общая рекомендательная лента (по умолчанию).

👥 Друзья — видео от взаимных подписок.

Автовоспроизведение при попадании видео в зону видимости и пауза при уходе с экрана.

Двойной тап по видео — мгновенный лайк, одиночный тап — пауза/воспроизведение с визуальной анимацией.

Кнопка включения/выключения звука в правом верхнем углу каждого видео.

Регулировка скорости воспроизведения от 0.5x до 2x через модальное окно.

Прогресс‑бар внизу видео показывает текущую позицию воспроизведения.

Индикатор загрузки (спиннер) поверх видео, пока оно не готово к показу.

Обложка видео отображается до начала воспроизведения — защита от чёрного кадра.

Поддержка изображений в ленте наравне с видео.

Кнопка обновления ленты — перемешивает видео и обновляет контент.

Pull‑to‑refresh на мобильных и поддержка прокрутки вверх на трекпаде.

Сообщение «Видео больше нет» в конце ленты.

Демонстрационный режим — если удалённые данные недоступны, показываются демо‑видео.

[!IMPORTANT]
Приложение работает полностью на клиенте. Для доступа к камере и микрофону требуется HTTPS или localhost.

🚀 Запуск
bash
# 1. Клонируйте репозиторий
git clone https://github.com/ваш-username/smotryu.git

# 2. Перейдите в папку
cd smtryu

# 3. Откройте index.html в браузере
# или запустите локальный сервер для доступа к камере:
python -m http.server 8000
# или
npx serve .
Откройте http://localhost:8000 — приложение готово к работе 🎉
